MODULE 01

HTML Foundations

HTML describes the structure and meaning of webpage content.

1. Headings and paragraphs

Use headings to organise content and paragraphs for normal text.

<h1>My website</h1>
<p>Hello!</p>

2. Links and images

Links connect pages. Images should include useful alternative text.

<a href="about.html">About</a>
<img src="photo.jpg" alt="Description">

3. Lists

Use ul for a bullet list and li for each item.

<ul><li>HTML</li></ul>
MODULE 02

CSS Styling

CSS controls the appearance and layout of HTML elements.

1. Selectors and color

Selectors choose which elements receive a style.

h1 { color: rebeccapurple; }

2. Spacing

Padding is inside an element; margin is outside.

.card { padding: 16px; margin: 12px; }

3. Responsive layout

Flexible widths and media queries help pages fit different screens.

width: min(100%, 700px);
MODULE 03

JavaScript Basics

JavaScript adds behaviour and responds to user actions.

1. Variables

Use const for values that will not be reassigned and let when they will.

const course = "HTML";

2. Conditions

Use if and else to make choices.

if (score >= 50) { /* passed */ }

3. Click events

Listen for clicks to update what visitors see.

button.addEventListener("click", handleClick);

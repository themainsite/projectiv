HTML Foundations

Give your web pages structure.

LESSON 01

Your first HTML page

HTML uses elements to tell a browser what each part of a page means.

<h1>Hello, world!</h1>
<p>I am learning to code.</p>
LESSON 02

Headings and paragraphs

Use headings to organise ideas and paragraphs for normal text.

<h1>My website</h1>
<h2>About me</h2>
<p>Welcome to my page.</p>
✦

CSS Styling

Control how your website looks.

LESSON 01

Change colours

CSS rules select an element and give it styles.

h1 {
  color: teal;
  background: #eefafa;
}
LESSON 02

Add spacing

Padding adds space inside an element; margin adds space outside it.

.card {
  padding: 20px;
  margin: 12px;
}

Make your website respond.

LESSON 01

Use a variable

Variables store information you can use later.

const learner = "You";
console.log("Welcome, " + learner);
LESSON 02

Make a function

A function is a reusable set of instructions.

function sayHello() {
  alert("Hello!");
}

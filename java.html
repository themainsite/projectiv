What is Java?

Java is a popular programming language used to build applications, enterprise software, backend systems and many other kinds of programs.

Java is known for its object-oriented approach and its ability to run on different platforms using the Java Virtual Machine (JVM).

Before you begin

To run Java programs on a computer, you generally need the Java Development Kit (JDK). You can also practise using an online Java compiler.

You do not need to install anything just to read these lessons and study the examples.

Java learning roadmap

Complete the eight lessons below in order.

Lesson 1 — Introduction to Java

Java programs are commonly written inside classes. A basic Java program has a main method where execution begins. 

public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Projectiv!");
    }
}

Understanding the example

  • class Main: Defines a class called Main.
  • main: The program's entry-point method.
  • System.out.println: Displays text.
  • Semicolon: Ends the statement.
Quick exercise

Which Java statement displays text on the screen?

System.out.println("Your message");

Lesson 2 — Variables and data types

A variable stores information that a program can use. Java requires you to specify the type of data a variable will hold. 

int age = 18;
double price = 25.50;
String name = "Alex";
boolean isLearning = true;
char grade = 'A';
  • int: Whole numbers.
  • double: Decimal numbers.
  • String: Text. String is a class, not a primitive type.
  • boolean: true or false.
  • char: A single character.
Quick exercise

Which data type is suitable for storing a person's name?

String

Lesson 3 — Operators

Operators perform calculations and comparisons.

int a = 10;
int b = 5;

int sum = a + b;
int difference = a - b;
int product = a * b;
int quotient = a / b;

Common operators include:

  • + Addition
  • - Subtraction
  • * Multiplication
  • / Division
  • % Remainder
Quick exercise

What is the result of 10 % 3?

1 — the remainder after division.

Lesson 4 — Conditions and decisions

Conditions allow a program to make decisions. The if and else statements are commonly used. 

int age = 18;

if (age >= 18) {
    System.out.println("Adult");
} else {
    System.out.println("Minor");
}

The program checks whether the age is at least 18.

Quick exercise

Which keyword provides an alternative when an if condition is false?

else

Lesson 5 — Loops

Loops repeat instructions. A for loop is useful when you know how many times you want to repeat an action. 

for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

This example prints the numbers 1 through 5.

Quick exercise

Which loop is often used when the number of repetitions is known?

A for loop.

Lesson 6 — Methods

A method is a reusable block of code that performs a task.

public class Main {

    public static void greet() {
        System.out.println("Welcome to Java!");
    }

    public static void main(String[] args) {
        greet();
    }
}

The greet method is called from the main method.

Quick exercise

Why do programmers use methods?

To organise code and reuse instructions.

Lesson 7 — Arrays

An array stores multiple values of the same type in one variable. 

String[] fruits = {
    "Apple",
    "Mango",
    "Orange"
};

System.out.println(fruits[0]);

Array positions start at index 0. Therefore, fruits[0] refers to Apple.

Quick exercise

What is the first index in a Java array?

0

Lesson 8 — Classes and objects

A class is a blueprint for creating objects. An object is an instance of a class. 

class Student {
    String name = "Alex";

    void introduce() {
        System.out.println("Hello, " + name);
    }
}

public class Main {
    public static void main(String[] args) {
        Student student = new Student();
        student.introduce();
    }
}
Quick exercise

Which keyword is used to create an object in Java?

new

PROJECTIV V2 — INSTALLATION

This is a visibly redesigned version of Projectiv with:
- A new dashboard and progress overview
- Lesson completion saved in the browser
- Course search
- Interactive HTML/CSS Code Lab with live preview
- A six-question quiz with saved points
- Dark/light theme toggle and mobile navigation

UPLOAD TO GITHUB:
1. Extract this ZIP on your phone.
2. In your GitHub repository, upload the six HTML files to the repository ROOT:
   index.html, courses.html, lessons.html, practice.html, quizzes.html, about.html
   Replace the existing files when GitHub asks.
3. Open your existing assets folder. Upload style.css and script.js into that folder.
   Replace files with the same names. Do NOT create assets/assets.
4. Commit the changes and wait for GitHub Pages to publish.

IMPORTANT:
- Keep the exact filenames and lowercase spelling.
- All progress is stored in the visitor's browser using localStorage.
- Google Fonts is an optional visual enhancement; the site works without it.
